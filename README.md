# curious-judge-text

Satu teks pendek untuk bounty make.fun **Make the AI judge feel curious**: satu adegan dapur yang tenang pukul tiga pagi, di dalamnya satu benda berada di tempat yang salah — dan narator hanya mengamatinya, tanpa menjelaskan.

Program `main.ts` (Node 22, tanpa dependensi, tanpa network) menulis teks itu secara deterministik ke `/output/entry.txt`.
